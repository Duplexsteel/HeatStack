Setup guide

From zero to a running bot in about 15 minutes. You start in dry run, so nothing is bought until you say so.

  1. Create your Kraken API key
  2. Install on Windows
  3. Dry run, then go live
  4. Run it 24/7 on a server
  5. Home Assistant (advanced)
  6. Open it on your phone
  7. Updates and help

1 · Create your Kraken API key

  1. Log in at kraken.com → Settings → API → Create API key.
  2. Give it a name like TradeBot and tick exactly these permissions:
    Query Funds Query Open Orders & Trades Query Closed Orders & Trades Query Ledger Entries Create & Modify Orders Cancel/Close Orders
  3. Leave everything else off. Save, and keep the page open - you'll copy the API key and the Private key into TradeBot.
Never tick Withdraw Funds. TradeBot tests every key and refuses keys that can withdraw.
Use this key only for TradeBot. If another program (a tax tool, another bot) uses the same key, both can fail - Kraken counts requests per key.

2 · Install on Windows

  1. Download TradeBot-Setup.exe from the link in your purchase email.
  2. Run it. Because TradeBot is new, Windows may show "Windows protected your PC". Click More info → Run anyway.
  3. TradeBot opens with a short welcome: accept the terms, choose This PC, paste your Kraken key and press Test & save key.

That's it - the bot runs every hour while TradeBot is open. Orders it already placed stay on Kraken even when your PC is off.

3 · Dry run, then go live

New installs start in dry run: the bot reads your balances and shows on the Bot tab what it would buy, but places nothing. Watch a few runs.

Happy with it? Go to Setup → Strategy, untick Dry run and press Save. In the same place you can:

  • pick your own coins and weights, e.g. BTC:40, ETH:25, SOL:10 (empty = default mix)
  • switch on Buy only if you never want it to sell
  • list coins it should never sell
  • set over how many months your cash is spread (12 by default)
Small budgets: Kraken has a minimum order size per coin. If a coin's monthly share is below it, that buy rolls over to the next month. TradeBot tells you at start-up when this happens.

4 · Run it 24/7 on a server

A small cloud server (Hetzner, DigitalOcean, Oracle and similar - a few euros a month) keeps the bot running around the clock.

  1. Create a server with Ubuntu (any recent version). The smallest size is plenty.
  2. Connect to it (your provider shows the ssh command) and paste: 
    curl -fsSL https://duplexsteel.github.io/Tradebot/install.sh | sudo bash
  3. When it finishes it prints a command like the one below. Run it on your own PC (Windows Terminal or PowerShell is fine), then open http://127.0.0.1:8765 in your browser: 
    ssh -L 8765:127.0.0.1:8765 root@your-server-ip
  4. The same welcome appears - choose This PC or server and add your key.

To update later, run the same install command again. Your key and settings stay.

The page on the server only listens to the server itself, so nobody on the internet can reach it. The ssh -L tunnel is your private door in.

5 · Home Assistant (advanced)

Running Home Assistant OS on a Raspberry Pi or mini PC? TradeBot can run there as an add-on, 24/7, with dashboard tiles.

  1. Home Assistant → Settings → Add-ons → Add-on store → ⋮ → Repositories, add the TradeBot repository URL from your purchase email.
  2. Install TradeBot, enter your Kraken key in the add-on's Configuration, start it.
  3. In the TradeBot desktop app choose My Pi / Home Assistant - the app becomes your cockpit for the bot on the Pi.

6 · Open it on your phone

  1. In TradeBot: Setup → Advanced → Allow phone access with PIN, choose a PIN, save and restart the app. If Windows asks about the firewall, allow private networks.
  2. On the same Wi-Fi: open http://<your-PC's-IP>:8765 on your phone and enter the PIN.
  3. Away from home: install the free Tailscale app on the PC (or server) and on your phone, then use the Tailscale address instead.

7 · Updates and help

When a new version is out, TradeBot shows a green banner with a download link. Install it over the old one - your settings stay.

Something wrong? Send us %APPDATA%\TradeBot\crash.log (Windows) or the output of journalctl -u tradebot -n 100 (server). They never contain your keys.
